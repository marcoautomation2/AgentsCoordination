How an agent running on this machine resets it to the state this
repository describes. reset.ps1 deletes what the repository does not
describe, copies the repository's home\ tree over %USERPROFILE% and its
data\ tree over C:\data, aligns the seven Fearless repositories in each
fearlessBranchN, registers the one scheduled task, and reboots.

Preconditions:
C:\data\accounts.txt is present.
Display 1920x1080 at 150% scaling.
Windows logs sonta in at boot; Brave is logged in to claude.ai.

Needed Tools, each at its default install path; only install if not present.
  winget install Git.Git
  winget install GitHub.cli
  winget install Brave.Brave
  winget install Notepad++.Notepad++
  winget install UB-Mannheim.TesseractOCR
  JDK 26 at C:\Program Files\Java\jdk-26.0.2, no JAVA_HOME
  git config --global user.name marcoautomation2
  git config --global user.email marcoautomation2@outlook.com
  git config --global core.autocrlf false
  Eclipse at C:\data\tools\eclipse, for EclipsePlugin work (not installed, just the portable version)

Actions:
  Once:
    git clone https://github.com/marcoautomation2/AgentsCoordination C:\data\AgentsCoordination
    git -C C:\data\AgentsCoordination remote add upstream https://github.com/MarcoServetto/AgentsCoordination
  Every reset:
    git -C C:\data\AgentsCoordination fetch upstream main
    git -C C:\data\AgentsCoordination reset --hard upstream/main
    & C:\data\AgentsCoordination\reset.ps1
